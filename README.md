# Sorata-Bee-Plots
Scripts in R for ploting 16S data from PacBio CCS reads analysed with HiFi-16S-workflow (https://github.com/PacificBiosciences/HiFi-16S-workflow).

## Description
You must set as working directory the file containing the results from HiFi-16S-workflow and identify the .biom file for further analysis.

### Alpha_diversity.R
This script gives a plot comparing alpha diversity and a .csv file with all the indexes.
### Rarefaction_curve.R
This script generates a rarefaction curve plot.
### Barplots.R
This scripts generates barplots at several taxonomical levels and also exports a .csv table with relative abundances for aeach taxa.
